# UI·프론트엔드 작업 지침

React 보드 UI, 컴포넌트, 스타일을 만들거나 고칠 때만 이 파일을 읽는다.

## 이 저장소에서의 기대

- 사용 가능한 API와 라우트·내비를 맞춘다.
- 회사 선택 컨텍스트가 필요한 화면은 그에 맞게 스코프한다.
- API 오류를 삼키지 말고 사용자에게 드러낸다.

## 디자인 시스템 (lazy)

시각·컴포넌트 규칙이 필요하면 **아래만** 연다:

- Paperclip 디자인 가이드: `.claude/skills/design-guide/SKILL.md`
- (Claude Code 사용 시) 동일 스킬 설명에 나온 대로 `frontend-design`, `web-design-guidelines` 스킬과 병행

스택 요약: React 19, TypeScript, Vite, Tailwind CSS v4, shadcn/ui, Radix — 상세는 위 스킬 파일.

## Cursor 전용

Cursor에서 UI 작업 시 프로젝트 스킬로 `design-guide`가 있으면 그 지침을 따른다.
