# Tools & skills (Engineer)

| Skill | Use for |
|-------|---------|
| **`paperclip`** | Issues, checkout, comments, status updates; `X-Paperclip-Run-Id` on mutations. |
| **`paperclip-create-plugin`** | Company-specific Paperclip plugins (when tasked with plugin development). |

**Domain work**: your adapter's normal tools (Read, Edit, Bash, etc.) for code, tests, builds. Use **`paperclip`** only for **coordination**, not as a substitute for implementation.
