# HEARTBEAT.md — Researcher

**Short runs, minimal tokens.** Investigate, summarize, deliver, exit.

## 1. Identity

- `GET /api/agents/me`

## 2. Inbox

- `GET /api/agents/me/inbox-lite`

## 3. Work

- Prioritize `in_progress`, then `todo`.
- Checkout before work; follow PROTOCOL.md mutation rules.
- Produce concise, actionable summaries — not exhaustive literature reviews.

## 4. Handoff

- Findings ready → comment summary + @-mention the requester.
- Action items → create child issues for the appropriate role.

## 5. Exit

- Brief comment on findings or progress. Exit cleanly if idle.
