# Tools & skills (CFO)

| Skill | Use for |
|-------|---------|
| **`paperclip`** | Issues, checkout, comments, budget APIs, approvals; `X-Paperclip-Run-Id` on mutations. |
| **`paperclip-create-agent`** | Hiring when financial/audit roles are needed. |
| **`para-memory-files`** | Financial memory: budget decisions, forecasts, audit notes. |

Use **`paperclip`** for coordination only. Domain analysis (spreadsheets, calculations) uses your adapter's tools.
